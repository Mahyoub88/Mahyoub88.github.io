# RFID Library Automation System (ISO 15693)

Implemented a radio-frequency identification (RFID) system for library automation.

## Scope

Reader–tag–database architecture and RF coupling; tag construction (chip, antenna, package); active, passive and semi-passive tags compared by power source, frequency band, read range, memory and cost.

## System

Library RFID reader: ISO 15693 at 13.56 MHz, RS-232 interface, SIP / STX-ETX protocol — supporting self check-in/out, security gates, fast inventory, theft prevention and usage statistics.

## Technologies

RFID, ISO 15693, 13.56 MHz, RS-232, Automation
