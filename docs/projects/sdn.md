# Software-Defined Networking — Automation & Video Streaming

Implemented an SDN environment with OpenDaylight, OpenFlow and Mininet, connecting a programmable network to a real IP network for configuration automation and video-streaming evaluation.

## Role

End-to-end design, implementation, programming, integration, testing and technical documentation.

## Automation

Used Postman and controller APIs to install XML-defined forwarding rules. Restored h4-to-h6 connectivity after removing the relevant switch flow table.

## Streaming

Built Python-defined topologies and evaluated video transmission from different hosts across a Mininet environment connected to a real IP network.

## Results

Verified connectivity restoration and observed different video quality between sender paths. Findings are qualitative; no unverified latency, throughput or percentage improvements are claimed.

## Technologies

OpenDaylight, OpenFlow, Mininet, Python, REST APIs, QoS, Video Streaming
